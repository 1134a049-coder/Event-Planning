# 米遊社團活動企劃書系統 (HoYoverse Club Activities Planner)

專為米哈遊主題社團（原神、崩壞：星穹鐵道、絕區零）設計之活動企劃書檢索、篩選、評分與社員心願分享系統。

## 🌟 核心功能特色
- **三大米遊主題分類**：原神（Genshin Impact）、崩壞：星穹鐵道（Honkai: Star Rail）、絕區零（Zenless Zone Zero）。
- **豐富活動企劃書庫**：涵蓋日常交流、競賽挑戰、文化創作、大型社課等多元企劃。
- **社員心願分享與統計**：
  - 支援「匯出代碼」分享自己有興趣的活動。
  - 支援「匯入代碼」解析社員心願並加入統計排行榜。
- **卡片評分與詳細企劃書彈窗**：完整呈現時程規劃、預算編列、物資清單與備案。
- **純靜態前端架構**：支援一鍵部署至 GitHub Pages，無需任何後端資料庫。

## 📁 檔案結構說明
- `index.html`：系統首頁結構與導航列
- `style.css`：全站視覺樣式與深淺主題
- `app.js`：核心互動邏輯與分享模組
- `activities.json`：企劃書資料庫
- `images/`：主題遊戲圖示與視覺素材

## 🚀 部署至 GitHub Pages
1. 將本資料夾中的所有檔案推送至您的 GitHub 儲存庫（Repository）。
2. 前往儲存庫的 **Settings** -> **Pages**。
3. 在 **Branch** 選項選擇 `main`（或 `master`），資料夾選擇 `/ (root)`，點擊 **Save**。
4. 等待 1~2 分鐘即可透過 GitHub 提供的網址線上體驗！
